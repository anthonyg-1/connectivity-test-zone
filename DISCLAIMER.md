# Disclaimer

connectivity-test-zone is intended for authorized security testing, asset
inventory, and network administration only.

Use this tool only against domains, hosts, networks, and systems that you own or
are explicitly authorized to test. You are responsible for complying with all
applicable laws, regulations, policies, and third-party service terms.

Optional evidence collection features can generate HTTP requests, nmap NSE
traffic, nuclei scanner traffic, OWASP ZAP baseline spider/passive-scan traffic,
and third-party enrichment lookups when you enable those switches. Do not enable
checks that are outside your authorization or rules of engagement.

This tool does not perform automatic exploitation, destructive testing,
credential attacks, shell delivery, persistence, evasion, or post-exploitation.

Nuclei findings, OWASP ZAP passive alerts, security header observations, and
service/version matches can be false positives or context-dependent. Treat them
as evidence requiring manual validation, not proof of compromise or confirmed
vulnerability.
